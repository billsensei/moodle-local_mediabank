# Security policy

Media bank tools (`local_mediabank`) is **Beta** software. Only the newest release gets security fixes, for Moodle 5.0 to 5.3.

**Please do not open a public issue, pull request or discussion for a security problem.** Report it privately through GitHub:
[Report a vulnerability](https://github.com/billsensei/moodle-local_mediabank/security/advisories/new). The full policy (what to include, how fast to expect an answer) is in
the [content type's SECURITY.md](https://github.com/billsensei/moodle-contenttype_mediabank/blob/main/SECURITY.md); it applies here too.
